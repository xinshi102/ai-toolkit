# Mac 决策收件箱

在本机已安装的 Mac CLI 适配器和独立协作窗口上使用。本分支记录技能规则；Windows `/console` 和 PowerShell 安装脚本不用于 Mac。

- Codex 持有唯一总计划并负责派发与独立验收；使用已验证的 DSH CLI 会话处理需要选择的公开或合成任务。
- 在本机协作工具中，由主控用 `decision_cli.py open` 把问题绑定到原工作包。用户在独立协作窗口的决策收件箱作答，结果持久保存，不自动唤醒或启动模型。
- 主控核对决定后用 `resume` 领取一次，在原 DSH 会话和原工作目录续做。重复回答、过期卡片和身份不符的续做不能生成第二次执行。
- 核对独立产物，协调器 `accept` 后用 `decision_cli.py close` 结案。遇到状态不明先查原尝试。未部署或未通过验证的环境，继续在聊天接力。

此流程不要求另建任务树，也不支持将回答当作范围之外操作的授权。

## 原版主控台的 Mac 适配

已部署的 Mac 主控台使用 Windows 四区布局和纯黑底色。项目目录只组织已登记的 Plan Map，计划节点和工作包结果分别沿用现有存储。长线项目可以包含技能分支，再挂具体计划。决策支持选项和原话，原话由主控核实并明确映射到已授权选项后续做。归档和同计划下的显示归属可以撤销。

已在本机验证免费 OpenCode 的面板拖拽回归、DSH Flash 原会话的两次决策续做，以及 Codex 两个额度窗口的本机快照。资源面板的 DSH/OpenCode 额度、统一预算与授权、桌面通知、多包调度和全新 Mac 安装仍待验收。本分支本次提交更新技能和使用说明，面板运行时通过本机桥接部署。
