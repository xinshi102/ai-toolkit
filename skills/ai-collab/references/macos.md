# Mac 决策收件箱

在本机已安装的 Mac CLI 适配器和独立协作窗口上使用。本分支记录技能规则；Windows `/console` 和 PowerShell 安装脚本不用于 Mac。

- Codex 持有唯一总计划并负责派发与独立验收；使用已验证的 DSH CLI 会话处理需要选择的公开或合成任务。
- 在本机协作工具中，由主控用 `decision_cli.py open` 把问题绑定到原工作包。用户在「总览 → 需要你决定」作答，结果持久保存，不自动唤醒或启动模型。
- 主控核对决定后用 `resume` 领取一次，在原 DSH 会话和原工作目录续做。重复回答、过期卡片和身份不符的续做不能生成第二次执行。
- 核对独立产物，协调器 `accept` 后用 `decision_cli.py close` 结案。遇到状态不明先查原尝试。未部署或未通过验证的环境，继续在聊天接力。

此流程不要求另建任务树，也不支持将回答当作范围之外操作的授权。
