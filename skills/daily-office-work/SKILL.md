# Daily Office Work

Use for bounded everyday work such as drafting a report, assembling a presentation webpage, creating or analyzing a table, or extracting structured data from supplied files. Follow the active project instructions and use the available document, spreadsheet, browser, or code tools that fit the deliverable.

## Work pattern

1. Identify the audience, purpose, source material, output format, and any deadline or size limit. If a missing fact changes the deliverable, ask; otherwise use a small reversible assumption and label it.
2. Work from supplied or explicitly approved sources. Preserve source paths, sheet/page/row references, and extraction criteria so another person can audit the result. Do not invent missing values; use blank/unknown and explain the rule.
3. Produce the requested artifact in the project workspace. Keep source files intact unless the user specifically asks to edit them.
4. Review content and the artifact itself: check facts against sources, calculations and units, links, headings, spelling, and layout at the intended screen/page size. Record what was checked and what remains uncertain.
5. Return the artifact path, a short summary, evidence, assumptions, and unresolved items. Publishing or sending to others requires explicit authorization.

## Deliverable cues

- **Report:** state the question and conclusion early; separate sourced facts, analysis, and recommendation; cite the source near each material claim.
- **Briefing webpage:** make the key message and decision easy to find; use responsive layout; verify navigation, links, and a rendered view when a browser/preview is available.
- **Spreadsheet/table:** preserve raw values on a separate sheet when useful; label columns, units, filters, formulas, and missing values; check totals and a few rows against the source.
- **Data extraction:** define fields and inclusion rules; keep one source locator per extracted record; flag ambiguous or conflicting entries instead of silently resolving them.

Do not treat successful file creation as acceptance. If visual inspection or source verification is unavailable, say so plainly.
