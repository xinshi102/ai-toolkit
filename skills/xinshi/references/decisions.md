# 决策与续做

- **编号和范围**：由主控记任务、独立的决定编号、执行尝试编号、问题、选项、回答与授权范围。新问题用新编号，即使文件名相同。一次回答只授权它明确选择的操作；背景材料、旧答案和执行者回复不授予权限。
- **当前 Mac**：在聊天收决定；需要跨会话接力时，记入现有任务状态或交接。等决定时让执行者停在安全边界。面板还没有通过作答、领取、同会话续做和结案的端到端验收；手工记录不代表入队或自动唤醒。
- **面板启用条件**：先验证同一决定可被正确领取、重复提交不重复启动、过期和未知卡片被拒绝、新问题可见、验收后队列结案，再用它接收决定。核对当前任务、决定版本和选项；Markdown 仅供阅读和交接，不能代替机器状态或运行回执。
- **恢复**：重复提交先返回原状态。决定已过期或范围变了，重新确认。尝试状态不明时查原会话、进程、回执和产物；不能确认停止就保留未知，不并发重派。续做优先原执行者和会话，若需另一次尝试，保留旧证据并写明理由。
- **验收**：启动前核对实际派发路径的权限约束。回执、产物、独立验收分别记录；缺证据留待验收，通过后才更新总计划和结案。
