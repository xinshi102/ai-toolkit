# 本机运行器接入

适用：任务确需跨聊天保存、后台子进程、依赖/资源调度或恢复，且宿主原生工具不足。普通任务及原生子agent足够时不增加此层。

项目内运行器为 `E:/AI-Workspace/Projects/Shared/Agent-Conventions/runtime/task_runner.py`，使用前读取同目录 README.md 并核实实际版本、测试和可用适配器。它的状态库属于任务项目，不让用户维护每个执行窗口。主控负责生成清晰的任务manifest、派发、回收、核验实际产物和更新总体任务状态。

运行器当前是试行实现，不是已经验收的通用后台平台。启动前根据真实task权限选择适配器，不以提示词取代权限边界；真实适配器的预检不能用local-test代替。解释壳层只读、外部工具限制与用户授权的实际关系。

任务状态持久化不证明聊天关闭后调度仍然存活。CLI控制进程退出、桌面客户端退出、系统重启是不同验收对象。关闭桌面与迁移项目根目录涉及当前会话连续性，须先保存交接并遵守用户退出/迁移约束，不能自动结束正在使用的聊天。

若某个适配器、事件唤醒或恢复能力仍未通过，明确标记缺口，继续其他可独立验证的工作。不要通过隐藏失败、调低目标或平均分来宣布整体完成。
