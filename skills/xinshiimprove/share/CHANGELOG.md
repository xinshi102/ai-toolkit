# 变更记录

规则：
- 任何对 `share/` 的修改都必须在此追加一条，并同步升级被改文件的版本号
- 废弃的规则从正文**删除**，在此记录其废弃原因**及全文**，保证正文始终只含当前生效内容
- 网页版使用时，人类粘贴的 `collaboration.md` 必须含版本号；AI 回报版本号以便察觉版本漂移
- **自 v1.4 起**，每条变更必须含 `governance.md` §版本与历史 规定的必填字段：层级 / 提案编号 / 关联观察 / 触发案例 / 试验记录 / 为什么低层解决不了 / 本次删除 / 影响已接入项目 / 变更内容 / 被删规则全文
- **自 v1.8 起**，正文只保留**最近 3 个版本**的完整条目，更早版本的完整原文见 `CHANGELOG_ARCHIVE.md`
