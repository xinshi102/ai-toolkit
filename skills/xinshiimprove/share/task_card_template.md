# 任务卡模板

> **触发场景**：M 档及以上任务建任务卡｜**不用读的情况**：S 档任务（不建卡）｜**行数**：75

版本：v1.1
更新日期：2026-09-21
上位文件：`collaboration.md`

规模档 **M 及以上必须建任务卡**，存放于项目 `tasks/<任务名>.md`。S 档不建，档位与验收清单写在自评报告里即可。

任务卡是**单个任务**的事实来源：档位、边界、拆分、验收方式都以它为准。它不复制 `collaboration.md` 的规则。

命名：`tasks/<任务名>.md`，任务名用小写英文加下划线。

---

复制下面代码块，另存为 `tasks/<任务名>.md`，逐节填写。标注「必填」的小节不得删除。

```markdown
# 任务：<任务名>

创建日期：YYYY-MM-DD
状态：进行中 / 已完成 / 已暂停 / 已放弃

## 档位（必填）
- 规模档：S / M / L / XL
- 干预档：A / B / C
- 声明人：人类 / AI 提议经人类确认
- 工时锚点（人类口头估计，仅供参考）：<如"大概一天"；没有则写"未给出">

## 目标（必填）
<一句话说明做完是什么样>

## 边界（必填）
- 做：<范围内的事>
- 不做：<明确排除的事>

## 预算（必填）
- 同一目标失败上限：<次数，默认 3>
- 其他上限：<时长 / 花费 / 无>

## 涉及文件（必填）
- <路径>：<新增 / 修改 / 删除>

## 不可逆操作清单（必填）
<列出本任务中所有不可逆操作及其回退方式；没有则写"无">
- 操作：<做什么>　回退：<怎么撤销，或"不可回退">

## 子任务拆分（L / XL 必填，M 可选）
| # | 子任务 | 产出 | 验收方式 | 状态 |
|---|--------|------|----------|------|
| 1 |        |      |          | 待开始 / 进行中 / 已验收 |
| 2 |        |      |          | |

## 验收方式（必填）
- 产物类型：可执行产物 / 文档产物 / 两者都有
- 可执行产物 → 验收脚本路径：<./acceptance/xxx>
- 文档产物 → 验收清单路径：<./acceptance/xxx_checklist.md>

## 档位变更记录
| 日期 | 变更 | 原因 | 是否经人类批准 |
|------|------|------|----------------|
| | S→M | | 升级无需批准 |

（降级必须填"是"并注明人类批准的原话或出处）

## 备注
<其他需要记住的约定>
```

## 填写规则

- 「不可逆操作清单」不得留空，无则明写"无"。该清单为空却实际执行了不可逆操作，视为违反协议。
- 「子任务拆分」在 L/XL 档必须在阶段 2 就填好并经人类确认，不得边做边加。确需新增子任务，按 `collaboration.md` §任务规模与干预档 的升级规则处理并在报告中说明。
- 任务结束时把「状态」改为「已完成」，不删除任务卡。
