# Claude Code 适配

> **触发场景**：在 Claude Code 中执行协议｜**不用读的情况**：使用其他工具时｜**行数**：33

版本：v1.2
更新日期：2026-09-21

公共约定见 ./_common.md，协作规则见 ../collaboration.md。本文件只写本工具差异。

## 入口文件
项目目录放 `CLAUDE.md`，内容固定为：

```markdown
请先读同目录 AGENTS.md，再按其中「必须先读」的引用，读 SHARE_ROOT 下的 ROUTER.md 和相关 skills 文件。
其余 share 文件按 ROUTER.md 的路由表按需读取，不要全量加载。
本文件不重复任何规则，一切以 AGENTS.md 与 collaboration.md 为准。
```

注意：`CLAUDE.md` 存在层级继承（上级目录与用户级 `CLAUDE.md` 也会被读入）。若上级文件与本套协议冲突，按 `collaboration.md` §裁决优先级 裁决；无法裁决时暂停提问。

## 权限与沙箱
- 文件读写与命令执行受 permissions 配置约束，超出范围需人类批准
- 被拒绝时：停下并报告，不绕路
- 若配置了 hooks，可能在工具调用前后插入额外行为；发现行为与协议不符时，按未识别状态处理

## 能力缺口
- 无原生桌面截图能力（除非项目另行提供截图工具）

## 降级方案
- 无法截图时，现场证据改为：命令原文 + 完整输出 + 相关文件片段，写入项目 `logs/`，并在报告中注明"本环境不支持截图"

## 本工具特有能力
- 可用子任务并行处理独立工作；并行任务不得并发修改同一文件
