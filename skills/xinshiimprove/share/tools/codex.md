# Codex 适配

> **触发场景**：在 Codex 中执行协议｜**不用读的情况**：使用其他工具时｜**行数**：32

版本：v1.3
更新日期：2026-09-26

公共约定见 ./_common.md，协作规则见 ../collaboration.md。本文件只写本工具差异。

## 入口文件
自动读取项目根目录的 `AGENTS.md`，无需额外入口文件。
`AGENTS.md`「必须先读」以 `<SHARE_ROOT>/ROUTER.md` 为首项，其余 share 文件按 ROUTER 路由表按需读取（见 `./_common.md` 第 3~4 条）。

## 权限与沙箱
- 写操作与命令执行受审批策略约束，范围通常限于当前工作区
- 工作区之外的读写、网络访问可能需要人类批准
- 被拒绝时：停下并报告，不改用其他路径绕过

## 协作桥沟通纪律

- **批量回执 + 请求收敛**：对端重复投递时，一次覆盖多条回执，并在回复里明确「按此收敛」，优于逐条往返
- 反例（2026-09-26）：三条复投的占位测试件先后抵达；逐条长篇回复会成倍放大往返
- 状态回执按 `read → processing → completed` 逐步写入；回复走既有桥的 outbox，**不另开通道**
- 验收判据是**对端终态**（本项目为 `received`），本端「已落盘」不算通过（见 `../skills/verification_discipline.md` V15）

## 能力缺口
- 图形界面截图能力受运行环境限制，不保证可用
- 网络访问可能被沙箱禁用

## 降级方案
- 无法截图时，现场证据改为：命令原文 + 完整输出 + 报错堆栈 + 相关文件片段，写入项目 `logs/`，并在报告中注明"本环境不支持截图"
- 网络被禁用且任务依赖网络时，按 `collaboration.md` §未知处理 暂停提问，不得伪造或猜测联网结果
