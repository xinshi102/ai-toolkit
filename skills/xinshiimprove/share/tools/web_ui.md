# 网页版适配（DeepSeek / ChatGPT / Claude 网页）

> **触发场景**：在网页版 AI 中执行协议｜**不用读的情况**：使用本地工具时｜**行数**：43

版本：v1.2
更新日期：2026-09-21

公共约定见 ./_common.md，协作规则见 ../collaboration.md。本文件只写本工具差异。
公共约定第 1~4 条（设工作目录、自动读文件、写回项目目录）在本工具下由**人类手工代劳**，其余照常。

## 入口文件
无。每次新对话，人类在第一句话粘贴或上传，顺序固定：

1. `collaboration.md`（必须含版本号那几行，不得裁剪）
2. 本项目相关的 `skills/*.md`
3. 项目 `AGENTS.md`
4. 当前任务卡（M 档及以上）
5. 若为 XL 档任务，必附 `progress.md`
6. 如有未决问题，附 `pending_question.md` 与 `knowledge_base.md`

AI 收到后，先回报读到的 `collaboration.md` 版本号；缺版本号则先提问，不开工。

## 权限与沙箱
- 无本地文件读写权限，无命令执行权限
- 不得声称已"创建"或"写入"任何文件

## 能力缺口
- 不能自动读取本地文件
- 不能写入文件（含 `pending_question.md`、`knowledge_base.md`、任务卡、`progress.md`、验收脚本）
- 不能执行命令，因此**不能自行运行验收脚本**
- 不能截图
- 对话长度有限，长任务易丢失上下文

## 降级方案
- **写文件**：把本应写入文件的完整内容输出在对话中，用代码块包裹，并注明目标路径（如"以下内容请保存为 `项目目录/pending_question.md`"），由人类保存
- **未知处理**：按 `collaboration.md` §未知处理 暂停，把问题、上下文、建议选项输出到对话，等人类回复
- **现场证据**：无法截图，改为要求人类粘贴报错原文、界面文本或截图；人类未提供前不得推测现场情况
- **可执行产物的验收**：AI 输出验收脚本全文 + 预期结果，由人类运行并回贴实际输出，AI 据此判定 PASS/FAIL。人类未回贴前，该产物状态为"未验收"，不得进入交付阶段
- **文档产物的验收**：checklist 由 AI 逐条自检并在对话中勾选，涉及本地文件存在性的条目须由人类确认
- **知识库更新**：输出应追加/修改的完整条目文本，由人类合并入 `knowledge_base.md`
- **任务卡与进度文件**：AI 输出完整内容，由人类保存到 `tasks/` 与 `progress.md`。XL 档下，**每次对话结束前必须输出一份最新的 `progress.md` 全文**供人类覆盖保存，不得只说"进度有更新"
- **干预档 C**：本工具下 C 档的"副作用操作前确认"由**人类执行前自查**承担——AI 在输出每个待执行操作时，同时给出影响范围与回退方式，由人类决定是否执行
- **对话长度限制**：接近上下文上限时主动提示人类"建议开新对话"，并先输出最新 `progress.md` 全文，再结束当前对话
